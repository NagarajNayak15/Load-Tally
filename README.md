# Load Tally – Smart Inventory Management System

Load Tally is an IoT-based inventory management web application that uses a **weight sensor** and an **ultrasonic sensor** to monitor stock levels in real time. The system helps automate inventory tracking, reduce manual checking, and provide accurate stock monitoring for warehouses, retail storage, and smart containers.

---

## Features

- Real-time inventory monitoring
- Weight-based stock measurement
- Ultrasonic distance/fill-level detection
- Web dashboard for live data visualization
- Low-stock alerts and notifications
- Sensor data logging and history tracking
- Responsive and user-friendly interface

---

## Technologies Used

### Hardware
- ESP32 / Arduino
- Load Cell Sensor
- HX711 Amplifier Module
- HC-SR04 Ultrasonic Sensor

### Software
- HTML
- CSS
- JavaScript
- Node.js / Express 
- REST API 
---

## System Architecture

```text
Sensors → Microcontroller → Backend Server → Web Dashboard
```
